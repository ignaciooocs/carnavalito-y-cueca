# Carnavalito y cueca

Guía de ensayo para el video de la actividad formativa de la semana 4 (MUSV0059): ritmos de la Zona Norte (carnavalito) y la Zona Centro (cueca).

Incluye la escaleta del video, el guion con teleprompter, los ritmos con audio para practicar, una pista guía para grabar por capas, la construcción de instrumentos caseros y los pasos de edición.

Página publicada con GitHub Pages: abre `index.html`.
